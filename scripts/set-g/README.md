# Set G: the independent builder's tools

These are copied byte for byte from the sealed set (`/root/aw-set-g/tools/`). `tools.sha256` and `SEAL.txt` are the sealed copies. Run `sha256sum -c ../tools.sha256` inside `tools/` to check the files.

The folder contains converters from each source's structured form to reference USFM, renderers for the documents the builder made, and the conversion checks.

It contains no Bible text, no downloaded source and no generated document. The sources and the rebuild steps are recorded in `docs/audit/set-g/GROUND_TRUTH.md`. Several texts are licensed CC BY-SA, so the documents and reference zips are not committed.
