# Spanish — complete individual AI editorial pass

Baseline: `64dadc0d1bb263362aa384951612e9395d705725`. All **4,296 Spanish leaves**, including unchanged strings and every Spanish plural branch, were read in numbered namespace batches. This is an AI language review, **not human native-speaker approval**. The JSON ledger records a retain, protected-retain or edit decision for every leaf, with the actual old/new text and key context. It serialises those editorial decisions; it is not a string-fingerprint coverage claim.

## Policy and glossary

- Address the user as **tú**. No switch to usted or vosotros in application instructions. Biblical quotations keep their own register.
- Use the established Spain-leaning vocabulary: **ordenador**, **añadir**, **Configuración**. This remains broadly intelligible Spanish; no regional Bible-book renaming.
- **Estudio bíblico** / **Enseñanza bíblica** remain separate; **Plantillas de estudio**, **Plantillas de enseñanza bíblica** and **Plantillas para la iglesia** are distinct.
- **Apunte** is a study finding; **nota** remains the verse/source annotation or a private Teaching note. **Texto** is a writing block; **Pasaje bíblico** is a Scripture block.
- **Fuentes**, **Biblioteca**, **Materiales**, **Manuscrito**, **Guía del líder**, **Guía del maestro**, **Hoja de preguntas**, **Hoja de trabajo** and **Hoja de apuntes** retain their established distinctions.
- Source table of contents is **Índice**, matching the existing Índice generado; the document body remains texto/contenido.
- POZETEK keeps the original seven parts, **Núcleo** and **Asunto / Afirmación / Tema**. Only the remaining usted instructions were brought into tú; the triplet and source-grounded examples are unchanged.
- All Ten-Step labels, guidance, examples and fields remain byte-for-byte unchanged. Provider/edition names and original biblical quotations remain recognisable and untouched.
