- **Bibelstudium / Bibelstudien** and **Bibellehre / Bibellehren** remain separate. Template type names such as Wortstudie and Personenstudie remain established names; generic entity navigation uses the approved terms.
- **Quellen** (pane/source records), **Bibliothek**, **Unterlagen**, **Präsentation**, **Gemeindevorlage**, **Manuskript**, **Fragenblatt**, **Arbeitsblatt**, **Mitschreibblatt**, **Gesprächsleitfaden** and **Stundenablauf** keep their established meanings.
