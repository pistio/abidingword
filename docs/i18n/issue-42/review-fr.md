## Register and terminology

- Address the application user as **vous**. Use imperative instructions and concise action labels. Match actual **Paramètres**, **Analyser la structure** and **Garder la clé** labels in recovery/setup guidance.
- Preserve **Étude biblique**, **Enseignement biblique**, **Modèles d’étude**, **Modèles d’enseignement biblique**, **Modèles pour l’église**, **Sources**, **Bibliothèque**, **Supports**, **Manuscrit**, **Guide de l’animateur**, **Guide de l’enseignant**, **Feuille de questions**, **Fiche d’activité**, **Feuille de notes** and **Plan de l’étude** as distinct concepts.
- Preserve POZETEK’s seven-section sequence, **Noyau**, subject/statement/theme distinctions and accepted theological examples. Only broken French coordination and reflexive **vous** agreement were corrected in POZETEK. Ten-Step wording and all 66 established Bible names remain unchanged.
- New unsupported-book names translate native enum display labels only; USFM IDs, source numbering and Greek/Latin distinctions remain exact. **1 Esdras (version grecque)** and **2 Esdras (version latine)** deliberately keep the source registry numbering rather than silently adopting a different confessional numbering. No Bible text is translated or modified.
- French **_many** applies to exact million multiples (`Intl.PluralRules('fr')`): 1,000,000/2,000,000/1,000,000,000 select many; 1,000,001 and 1,000,000.1 select other. The noun requires **de/d’** after a million count, including digit notation. Abbreviated units such as **min**, bare counts and noun-free ellipses do not receive an invented noun. Possessives/definite articles and `+` counts are recast as noun-first labels with the count separately shown where this reads more naturally.
