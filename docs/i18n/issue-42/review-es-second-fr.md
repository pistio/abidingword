French-specific reference consulted for the disputed numeral point: [Guide de rédaction administrative, 2006](https://pdfcoffee.com/guide-redac-2006-2-pdf-free.html), “Avec million, milliard, etc., il faut employer la préposition de avec le nom qui suit, que l’on écrive le nombre en chiffres ou en toutes lettres : 1 000 000 d’habitants”. The source is used only to resolve that grammar point, not as application-content authority. The [OQLF note on writing million/milliard](https://vitrinelinguistique.oqlf.gouv.qc.ca/21647/la-typographie/nombres/ecriture-de-million-et-de-milliard) distinguishes written-out large-number nouns from exact numeric notation; symbolic measurement units are a separate construction from the UI nouns inspected here.
