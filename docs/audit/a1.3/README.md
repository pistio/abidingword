# Phase A1.3 evidence

The 113 disclosed editions (development corpus and Sets B–G), read by the
A1.3 candidate and compared with the A1.1 structural run and the frozen
v0.24.7 recogniser (`c96756d`). These are regression measurements on known
documents, not independent evaluation. The report is
`docs/recognition-a1.3-non-epub-safety.md`.

| File | What it holds |
|---|---|
| `cases.md` | Each of the 20 wrong and 2 nonexistent verified verses: the source, how it was accepted, its origin, what was done, its test |
| `regression.md` | Totals and every edition that changed from A1.1: correct verified, wrong, not in edition, conservative refusals |
| `data/editions.json` | The same four measures and caught errors, per edition, for v0.24.7, A1.1 and A1.3 |
